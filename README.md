# IT3130 Git Basics Lab
## Purpose
This repository demonstrates a basic Git workflow for IT3130.
## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation
## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push
## What I learned
I learned about Git and Version control.
Learned about to connect with github repository.
- Staging: Selecting the specific code changes I want to package together before saving them.
- Commits: Taking a permanent snapshot of my staged changes with a short message so I can track my project history.
- Remotes: Connecting my local code to a cloud service like GitHub so my work is backed up and easy to share.
